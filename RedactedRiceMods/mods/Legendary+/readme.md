# Legendary Pilot Level Up Skills
Rare, powerful pilot level up skills that can only appear in the second skill slot,
once per run, and at half half as often (by default). Boost your pilots to the next
level!

Enable and disable individual skills in the CPLUS+ Modify Pilot Abilities Menu.
